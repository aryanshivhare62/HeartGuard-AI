## 9. What This Means for HeartGuard AI

- Statlog must **not** be used as an independent external validation set because it is derived from Cleveland data.
- Using Statlog rows in any test set while training on Cleveland would constitute data leakage.
- Statlog can be used to verify preprocessing logic or as a sanity check, but not as a generalisation benchmark.
- The four external validation datasets (Hungary, Switzerland, VA Long Beach) remain appropriate for zero-shot generalisation experiments.
